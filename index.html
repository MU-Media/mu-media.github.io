MU Media Insights

MU Media Insights is an internal analytics tool operated by the MU Media team. It lets the team connect the TikTok accounts it owns and see each account's profile statistics and video performance in one private dashboard and a daily summary.

What it does

  • Signs in with TikTok (Login Kit) only for accounts the team owns.
  • Reads basic profile info, profile stats (followers, likes, video count) and the list of the account's own public videos with their view, like, comment and share counts (Display API).
  • Stores these numbers once a day to show trends over time.

What it does not do

  • It does not post, edit or delete anything on TikTok.
  • It does not read messages, followers' identities or any other user's private data.
  • It is not offered to the public; there is no sign-up.
